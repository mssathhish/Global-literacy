An end-to-end data analytics project exploring how literacy, illiteracy, GDP, and education levels relate across 190+ countries (1990–2023).

🌍 Data sourced from Our World in Data (literacy, illiteracy, GDP, schooling years)
🧹 Cleaned, merged, and engineered features like literacy gender gap and GDP-per-schooling-year
🗄️ Structured into a SQLite database with 13 analytical SQL queries
📊 Full EDA notebook with correlation analysis and country rankings
🖥️ Interactive Streamlit dashboard with Global Overview, SQL Query Runner, and Country Profile pages
📈 Built with Python, Pandas, SQLite, and Plotly
